# contao-qgis-bundle
Dieses Bundle ermöglicht das Übertragen von QGIS2WEB-Projekten in  das CMS Contao. 

Zurzeit befindet sich das Bundle im experimentellen Stadium. 

Folgende Funktionen sind implementiert  

1. Karten (OpenStreetMap)
2. Ebenen (implementiert el.layers)
3. Eigenschaften (implementiert ol.features) 
4. Stile (implementiert ol.style)
4. Verwerndung von Elementen aus ol-ext

Das bundle ist experimentell und noch nicht für den produktiven Betrieb geeignet.
